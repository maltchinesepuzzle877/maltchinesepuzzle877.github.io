📋 Overview

Resolve-Caption-Flow manages subtitle tasks for long video projects. It uses local AI to fix errors and formats text for DaVinci Resolve. You process media using FFmpeg tools to ensure high quality. The software keeps your data private by running tasks on your own hardware.

✨ Key Features

  • Private Processing: Your media files stay on your machine.
  • AI Correction: The system uses language models to fix transcription errors.
  • Custom Knowledge: Upload style guides or terminology lists for accurate captions.
  • Resolve Ready: Generates files that import directly into DaVinci Resolve timelines.
  • Fast Processing: Built on reliable media tools for handling long video content.

💻 System Requirements

Ensure your computer meets these standards to run the application well:

  • Operating System: Windows 10 or 11 (64-bit).
  • Memory: 16GB RAM or higher recommended for long videos.
  • Storage: 2GB available disk space.

Start your first project by selecting your video file in the main application window. The software analyzes your audio track and creates a draft subtitle file.
